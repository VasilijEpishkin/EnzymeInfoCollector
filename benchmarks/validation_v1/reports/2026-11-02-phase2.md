# Validation v1 — Phase 2 independent source and chemistry checks (2026-11-02)

**Status:** Actual bounded source-backed live checks on the commit immediately
preceding this validation branch. The CLI export and parser logic is unchanged.
A later CLI/raw source request may drift and should not be scored against this
snapshot without re-checking its recorded SHA-256.

**Three different scopes:**
- (A) Exact UniProtKB->Rhea master+direction IDs versus Rhea-published
  `rhea2uniprot_sprot.tsv`. This is cross-source mapping consistency.
- (B) ECO and citations **per Rhea identifier** directly against original
  UniProtKB REST JSON; preserving an absent code/PMID, not inferring one.
- (C) Rhea SPARQL `rh:side` and `rh:coefficient` with actual ChEBI URI,
  compared independently with `reference_cli` output.
These are not wet-lab proof, global enzyme completeness or a demonstration
of physiological substrate/product direction.

## C. Rhea RDF sides, coefficients and ChEBI identity

The independent check used the **actual official SPARQL binding rows** from
each reference result's source query URL. Exact SHA-256 matched its
published query digest; the members were independently parsed and
compared by (master ID, left/right side, CHEBI ID, Decimal coefficient).
The compact reference manifest is `chemistry_cases.json`; it stores each
official response SHA and all member tuples.

| UniProt | Rhea master IDs | RDF participant rows | Result |
| --- | ---: | ---: | --- |
| P04040 | 1 | 3 | pass |
| P05023 | 1 | 9 | pass |
| P00918 | 2 | 7 | pass |
| P04075 | 1 | 3 | pass |
| P22303 | 1 | 5 | pass |
| **Total** | **6** | **27** | **5/5 pass** |

Key traceability cases:
- P04040 RHEA:20309: **left 2 × CHEBI:16240 H2O2; right 2 ×
  CHEBI:15377 H2O and 1 × CHEBI:15379 O2**.
- P05023 RHEA:18353: nine equation-side participants, including separate
  Na+ and K+ positions on both sides, with original exact coefficients.
  Do not infer which side is extracellular/physiological by simply using
  left/right RDF sides.
- ChEBI canonical-vs-secondary REST checks: CHEBI:5585 -> CHEBI:15377
  (**water**) and CHEBI:5584 -> CHEBI:15378 (**hydron**). The canonical
  and corresponding secondary endpoint returned byte-identical JSON
  SHA-256 per pair. Water and hydron remain **distinct identities**, not
  interchangeable protonation variants. See `chebi_aliases.json`.

## D. Real unsupported and network boundary cases

- `reference_cli P00533`: **failure expected**, actual error
  `Rhea RDF chebi binding is missing or not uri`, consistent with an
  unsupported compound/complex Rhea participant. No fabricated ChEBI ID.
- `reference_cli P00690`: **failure expected**, no direct numeric
  UniProt->Rhea catalytic annotation; this is unknown, not negative biology.
- Later checks on `P00505` timed out and on `P60174` and `P0A799`
  encountered transient `rest.uniprot.org` HTTP 503. Those attempts are
  **not counted as biological, chemistry or parser failures**.

## Code verification, limitations, next work

Added standalone, opt-in `phase2_evidence.py`, `phase2_chemistry.py`,
two compact official observation manifests and focused offline regression
tests. No new runtime dependencies or changes to legacy/production APIs.
Data are observed live snapshots, not pinned official release archives.

**Not yet established:** any biology-level false-negative/positive rate;
complete mapping in all UniProtKB entries; chemical structure/pH/charge
truth for all ChEBI identities; direct compound/complex RHEA-COMP support;
source-specific physiological direction in a general transporter graph;
live full `discover_cli --enzyme` path (ambiguity and selection bias);
and full UI traversal/accessibility.
