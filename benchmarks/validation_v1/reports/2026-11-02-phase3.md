# Phase 3 live discovery smoke — 2026-11-02

**Scope:** One-step user-facing name or EC → bounded UniProt selected
candidate → UniProt direct Rhea → Rhea RDF/ChEBI reference → Graph
CATALYZES projection. No global coverage or biological accuracy claim.

**Version:** premerge branch validation/phase3-discovery-workflows
(commit 668ad6a..., plus subsequent guardrail corrections). Python
3.11 remote network runtime. Inputs are exactly those specified in
discovery_cases.json. Positive records were checked against official
UniProt source SHA and master IDs from cases.json. Network retries and
query order may change upstream results.

**Overall:** 7 scenarios, 4 passed and 3 inconclusive.
**Zero confirmed extraction/graph mismatches in the scored positive cases.**
Do not treat inconclusive API failures as biological false negatives or
evidence of zero enzymatic activity.

The first two successes were observed using the phase-3 runner with
source SHA and graph CATALYZES checks. The pig-amylase negative case
used the same run_case function invoked on the two final cases from the
repository directory, with a real live discover_cli process. The initial ambiguous-name candidate, dehydrogenase, was a poor test:
ExPASy has an exact alternative name that resolves to one EC, even though
many other names contain that word. It was changed to luciferase, which
has **4 exact EC matches** in the observed ExPASy catalogue. The corrected
command was live-checked through discover_cli: exit 1, explicit list
of four EC numbers and guidance to pass --ec, and no output file.
The prior dehydrogenase timeout is excluded from the corrected matrix.

Previously, a direct manual live check with EC 3.2.1.1 and exact
Sus scrofa taxon 9823 also returned P00690 with explicit
no-direct-Rhea failure, consistent with the benchmark's expected
unknown status. A manual ExPASy Catalase name resolution and UniProt
P04040 candidate selection both succeeded. Some retries of the full
name path failed during transient UniProt service outages, then
subsequently succeeded with the same immutable direct annotation.

## What is not established

- Global recall of EC/name discovery, complete per-EC candidate sets,
  UniProt search ranking or stability, or taxonomic coverage.
- Independent wet-lab truth or kinetics.
- Successful live TrEMBL name/EC discovery, translocase, bacterial PGK,
  or ambiguous-name handling under healthy upstream conditions.
- Full chemistry validation on all seven cases (phase-2 has a separate
  official Rhea RDF/ChEBI benchmark for five selected proteins).
- Rhea/CheBI query timestamps do not make a fully pinned release archive.

## Reproduction

From repo root:

    python -m benchmarks.validation_v1.phase3_discovery \
      --results-dir /tmp/eic-phase3 --max-cases 7 --timeout 90 \
      -o /tmp/eic-phase3/report.json

The command is **opt-in networked**, not default CI. Review the
individual statuses; re-running upstream_failure scenarios may become
pass or reveal a concrete code defect. Source_drift and selection_drift
remain inconclusive until reference snapshots are refreshed/re-audited.
