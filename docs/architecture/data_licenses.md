# Data-source licensing and attribution

Verified against public source documentation on 29 October 2026.

| Source | License | Official documentation |
| --- | --- | --- |
| UniProtKB (copyrightable database content) | Creative Commons Attribution 4.0 International (CC BY 4.0) | [UniProt API documentation](https://www.uniprot.org/api-documentation/support-data); [UniProt SPARQL VoID license declarations](https://sparql.uniprot.org/.well-known/void) |
| Rhea | Creative Commons Attribution 4.0 International (CC BY 4.0) | [Rhea license and disclaimer](https://www.rhea-db.org/help/license-disclaimer) |

The sources permit reuse, including commercial use, subject to **attribution**.
Include credit to UniProt Consortium and Rhea, retain source URLs and release
metadata, and indicate modifications where appropriate. This document is
project guidance, not a legal opinion.

The experimental evidence JSON export embeds source attribution. No bulk
UniProtKB or Rhea snapshot is committed to this repository. Before adding
other sources (BRENDA, SABIO-RK, KEGG, MetaCyc), review their **separate**
license and API conditions; do not infer their terms from UniProt/Rhea.

Useful source publications and citation instructions should also be linked
in a future hosted interface and accompanying research outputs.
